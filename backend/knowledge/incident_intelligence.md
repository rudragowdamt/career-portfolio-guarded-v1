# AI-Powered Integration Incident Intelligence
Portfolio project: AWS API Gateway → Lambda → compact multinomial logistic-regression severity classifier → Amazon Bedrock Nova Lite for incident summaries and probable RCA hypotheses → ServiceNow REST API for incident creation/update. Used synthetic incident data, deterministic correlation to reduce duplicate tickets, AWS Secrets Manager, SAM/CloudFormation, CloudWatch, pytest, GitHub. RCA is a hypothesis and requires human validation. Solved Lambda package size issues by separating training dependencies from inference. This is a hands-on project, not claimed as a production client deployment.
